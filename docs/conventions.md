# Conventions

Authoring conventions for spex docs, skills, and schemas. For term definitions see [glossary.md](./glossary.md).

## Path placeholders documentation convention

A placeholder marks a part of a path the reader must replace with a real value. Write placeholders in angle brackets with a lowercase, hyphenated name:

```text
<workspace-root>/spex/biz-specs/<spec-id>.yaml

e.g. pepperoni-pizza/spex/biz-specs/BIZ-PLACE-PIZZA-ORDER.yaml
```
