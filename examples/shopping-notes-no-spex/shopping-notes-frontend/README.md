# shopping-notes-frontend

Small example shopping notes application that let's user note down shoping items to not forget to buy them when visiting a store.

React SPA + TypeScript UI (Vite).

## Running

```sh
npm install
npm start # Serves http://localhost:5173
```

## Testing

```sh
npm install
npx playwright install chromium
npm test
```

Run `npm run test:unit` or `npm run test:e2e` to run either suite on its own.
